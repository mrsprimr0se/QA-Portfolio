
# Test Evidence — SpaceShooter

Folder zawiera materiały dowodowe dokumentujące
rzeczywiste testowanie manualne gry SpaceShooter.

## Rodzaje materiałów

- Zrzuty ekranu z Unity.
- Dokumentacja konfiguracji obiektów.
- Materiały potwierdzające wykonanie testów.

## TC-006 — Naliczanie punktów

Podczas testowania mechanizmu naliczania punktów
przeprowadzono dodatkową weryfikację konfiguracji
obiektu Player oraz prefabu Bullet.

W Unity Inspector potwierdzono wartość Points = 1,
zgodną z zaobserwowanym przyrostem wyniku.
